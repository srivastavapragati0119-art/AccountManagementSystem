# AccountManagementSystem
A CLI-based Account Management System in Java for handling core banking operations—including account creation, deposits, withdrawals, balance checks, and account details—using object-oriented principles and dynamic state management.

Account Management System
A Java command-line application that simulates basic banking operations. Built with object-oriented design, it allows users to manage bank accounts, perform monetary transactions, and inspect account state dynamically.

Features
Create Account: Open a new bank account with an Account Number, Holder Name, and Initial Balance.

View All Accounts: Display a comprehensive list of all registered accounts.

Deposit Money: Add funds to a target account with real-time balance updates.

Withdraw Money: Withdraw funds with built-in checks for negative amounts and insufficient balance.

Check Balance & Account Details: Look up exact balance details or full profile information by Account Number.

Technical Stack
Language: Java (JDK 8 or higher)

Core Concepts: Object-Oriented Programming (Account class), static methods, menu loops, validation logic, and input handling with Scanner.
